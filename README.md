# Diachronic word vectors, 1800s–1910s

Copy of Pedrazzini, Nilo & Barbara McGillivray (2022), *Diachronic word embeddings from 19th-century British newspapers*, Zenodo, https://doi.org/10.5281/zenodo.7181682 (CC BY 4.0), gzip-compressed for the TRIFECTA workshop.

The files are attached to the release `vectors-v1`: one word2vec text file per decade (`1800s-vectors.txt.gz` … `1910s-vectors.txt.gz`), aligned to the 1910s.
